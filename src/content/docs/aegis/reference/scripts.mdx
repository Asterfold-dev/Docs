## Development

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start the dev server on port 3001. |
| `npm run build` | Production build. |
| `npm run start` | Serve the production build with srvx. |
| `npm run preview` | Preview the production build locally. |
| `npm run typecheck` | TypeScript check. |
| `npm run lint` | ESLint. |
| `npm run format` | Format with Prettier. |
| `npm run check` | Check formatting. |

## Database

| Command | Purpose |
| --- | --- |
| `npm run db:push` | Push the schema to a development database. |
| `npm run db:generate` | Generate migrations after a schema change. |
| `npm run db:migrate` | Apply migrations with Drizzle Kit. |
| `npm run db:migrate:prod` | Apply committed migrations without Drizzle Kit. |
| `npm run db:backfill-usernames` | Backfill usernames from email prefixes. |
| `npm run db:studio` | Open Drizzle Studio. |

## Accounts and tests

| Command | Purpose |
| --- | --- |
| `npm run auth:create-admin` | Create an operator account. |
| `npm run auth:generate` | Regenerate the Better Auth Drizzle schema. |
| `npm run test:security` | Run the 21-check security proof suite. |
| `npm run test:oidc` | Run the OIDC authorization-code flow test. |

The admin and OIDC test commands expect a running server and database. See the
[security guide](../../operations/security/) for the security suite environment
variables.
