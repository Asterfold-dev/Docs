Aegis is a lightweight, self-hosted **OpenID Connect** provider with a shadcn
admin console. It is designed for a small team that wants standard OIDC,
passkeys, TOTP, groups, session policy, and self-service account management
without running Redis or a second control plane.

## What it does

| Area | Details |
| --- | --- |
| **OIDC** | Authorization code with PKCE, discovery, JWKS, UserInfo, introspection, revocation, and RP-initiated logout. |
| **Second factors** | TOTP with backup codes, plus passkeys as a replacement for the code at the second-factor step. |
| **Applications** | Register, edit, disable, rotate secrets for, and delete OIDC clients. Restrict clients to groups. |
| **Console** | Users, groups, applications, sessions, analytics, health, settings, and audit events. |
| **Account area** | Profile, username, password, passkeys, TOTP, own sessions, and group memberships. |
| **Footprint** | One Node process and one PostgreSQL database. No Redis. |

## Stack

| Layer | Choice |
| --- | --- |
| Framework | [TanStack Start](https://tanstack.com/start) and [React 19](https://react.dev) |
| Authentication and OIDC | [Better Auth](https://www.better-auth.com) |
| Data | [Drizzle ORM](https://orm.drizzle.team) and [PostgreSQL](https://www.postgresql.org) |
| UI | [Tailwind CSS 4](https://tailwindcss.com) and [shadcn/ui](https://ui.shadcn.com) (Base UI) |
| Runtime | Node 22+ via [srvx](https://srvx.h3.dev) |

The source lives in [Asterfold-dev/Aegis](https://github.com/Asterfold-dev/Aegis).
